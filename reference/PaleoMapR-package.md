# PaleoMapR: fossil-corrected paleogeographic maps in a point-and-click editor

Start the editor with
[`run_app()`](https://stratigraphy.github.io/PaleoMapR/reference/run_app.md).
The first time,
[`pm_setup()`](https://stratigraphy.github.io/PaleoMapR/reference/pm_setup.md)
downloads the open data sets (PaleoDEMs, PaleoCoastlines, PBDB,
Macrostrat, sea level, HadCM3L climate) into a working folder and builds
the corrected grids of the Silurian ages.
[`pm_load()`](https://stratigraphy.github.io/PaleoMapR/reference/pm_load.md)
gives the functions behind the editor for use in an R script.
